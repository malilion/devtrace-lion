# Privacy Policy

**Effective Date: September 2026**

DevTrace Lion is created and maintained by Malilion as an open-source browser developer tool.

### 1. No Data Collection
DevTrace Lion does **NOT** collect, store, transmit, or monetize any personal data, browsing history, network activity, or device identifiers.

### 2. Local-First Processing
All network inspection, JSON diffing, code snippet generation, and secret masking occur 100% locally on your machine within the browser's DevTools execution sandbox.

### 3. In-Memory Session Lifetime
All captured request records and response bodies are stored strictly in volatile RAM for the duration of the current DevTools panel session. Once the DevTools window is closed, all records are permanently flushed from memory.

### 4. Zero Third-Party Services & Telemetry
DevTrace Lion contains:
- No tracking pixels
- No analytics services (e.g. Google Analytics, Mixpanel, Sentry)
- No external scripts or remote font CDNs
- No cloud storage synchronization

### 5. Contact
Questions regarding this policy may be directed to `privacy@malilion.dev` or via issue submission on GitHub.
